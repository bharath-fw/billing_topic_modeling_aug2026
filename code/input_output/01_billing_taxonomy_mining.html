Brightspeed Billing — Taxonomy Mining & Topic Modeling (v2)

Jupyter Notebook · Python · 10 sections · No outputs (static conversion)

Markdown

What this notebook does. 7 months of Brightspeed call data (Jan–Jul 2026) are turned into a self-organized billing taxonomy. Every step runs on BGE-large embedding vectors (BAAI/bge-large-en-v1.5, 1024-d); text/keywords are used only to name and describe the mined topics afterwards.

The seed taxonomy files are reference material only — we never copy their labels.

YTD calls (5.0M) billing rows (~0.8M) │ collation: Root Cause + Reason │ mined on embeddings only ▼ ▼ heuristic Billing/Payments label ──▶ Billing Kernel (P/R/F1 tuned) │ ▼ K-Means on BGE embeddings (silhouette-tuned, 40 clusters) │ ▼ leaf topics (keywords + representative text per cluster) │ agglomerative on centroids ▼ 2-level taxonomy (Category ▸ Subcategory) ── mined, not seed │ ┌────────────────────┼────────────────────┐ ▼ ▼ ▼ GLVQ (90/10) SOM 20x20 top-3 scoring prototype model cell keywords → XLSX + 3D topography

2. Stage A — Billing / Non-Billing segmentation kernel

The first narrow is: is this call billing-related? We train a binary classifier on BGE embeddings using the heuristic Billing/Payments Primary Call Reason signal as the label, then tune a decision threshold on a held-out 10% to maximise F1. The saved kernel can then segment any call text.

4. Stage C — which clustering algorithm grooms the taxonomy best?

We compare candidates on the billing embeddings using criteria that matter for taxonomy grooming: silhouette (cohesion/separation), coverage, per-month stability, and how well each cluster maps to a seed topic (interpretability). K-Means wins on this data: full coverage, best silhouette, and the most stable silhouette across all 7 months.

Code 
table = pd.read_json(ARTIFACTS_DIR / "clustering_comparison_table.json")
print(table.round(4).to_string())
best = C.choose_best(table)
print(f"\nrecommended algorithm for taxonomy grooming: {best}")

5. Stage D — mine the self-organized taxonomy

taxonomy_mining.mine() does the grooming:

  1. fine K-Means clusters on the embeddings (40 clusters, silhouette-tuned);
  2. every cluster becomes a leaf topic — named from its own representative text, described by its own top TF-IDF keywords (display only);
  3. cluster centroids are agglomeratively grouped into coarse categories.

Clusters too small to trust fold into Other Category :: Misc/Other.

Code 
mined = json.loads((DATA_DIR / "taxonomy_mined.json").read_text())
n_cat = len(mined["categories"])
n_sub = sum(len(c["subcategories"]) for c in mined["categories"])
print(f"mined taxonomy: {n_cat} categories, {n_sub} subcategories")
for cat in mined["categories"][:4]:
    print("\n▍ " + cat["name"] + f"  ({cat['count']:,} calls)")
    for s in cat["subcategories"][:4]:
        print(f"   • {s['name']}  [{s['count']:,}]  kw={s['keywords']}")

6. Stage E — GLVQ prototype model (90/10, validated)

Generalised LVQ refines one prototype per mined leaf so leaves separate maximally while keeping coverage. It is trained on a 90/10 split and its held-out accuracy is reported. The trained model is what we score with.

Code 
model = GLVQ.load(ARTIFACTS_DIR / "glvq.joblib")
active = json.loads((ARTIFACTS_DIR / "glvq_active_keys.json").read_text())
print("active leaves:", len(active["active_keys"]))
print("prototypes:", model.prototypes_.shape)
top, sim, prob = model.predict_proba_topk(X[:2000], 3)
print("mean top-1/2/3 confidence:", prob.mean(0).round(3))

7. Stage F — Kohonen SOM 20×20 + 3D topography

The SOM projects the billing embeddings onto a 20×20 grid. Each call lands in its Best-Matching Unit (BMU) cell; cells accumulate counts to form the topographic map. The cell table lists each cell's coordinates, call count, top keywords, and dominant mined subcategory.

Code 
som = KohonenSOM.load(ARTIFACTS_DIR / "som20.joblib")
density = som.accumulate_density(X)
print("cells with calls:", (density > 0).sum(), "· total:", int(density.sum()))
print("peak:", int(density.max()), "calls/cell")
cell_df = pd.read_csv(OUTPUTS_DIR / "som_cells.tsv", sep="\t")
cell_df.head(12)
